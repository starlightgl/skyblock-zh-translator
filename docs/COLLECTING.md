# 参与原文收集

SkyBlock 中的菜单按钮、系统消息、侧边栏、Tab 列表等文本不在任何物品数据库中，只能在游戏里实际看到后记录。本模组会在游戏过程中自动把看到的英文记录到本地文件，参与者正常游戏后把文件发给维护者，汇总翻译后加入下一版的术语表。

## 参与步骤

1. 安装 [Fabric Loader](https://fabricmc.net/) 及前置模组：Fabric API、YetAnotherConfigLib、ModMenu。
2. 在 [Releases](https://github.com/starlightgl/skyblock-zh-translator/releases) 页面下载 `1.5.1-zh.3-beta.7` 或更新版本中与游戏版本对应的 jar（`+mc26.2.jar` 或 `+mc26.3.jar`），放入 `mods` 目录。
3. 正常游戏。收集默认开启，不需要配置 AI 接口，也不需要任何操作。
4. 游戏一段时间后，将游戏目录下的 `config/npc_translator_text.tsv` 发给维护者。建议把文件改名为自己的昵称（如 `小明.tsv`），便于区分。

输入 `/translate collect` 可查看各类别已收集的条数。

## 收集方式

| 内容 | 收集方式 |
|---|---|
| 菜单中的物品名称与描述 | 打开菜单约 1 秒后自动记录整页；分页菜单需逐页翻看 |
| 背包中的物品 | 鼠标悬停时记录 |
| 侧边栏、动作栏、屏幕标题与副标题、Boss 血条、聊天 | 显示时自动记录 |
| Tab 列表 | 页眉页脚自动记录；中间的信息栏需按住 `Tab` 显示一次 |
| 头顶名字与全息文字 | 显示在附近时记录 |
| 其他模组的提示（如价格表格） | 显示时记录 |

收集只受设置中「原文收集」一个开关控制，与是否开启翻译、使用哪种译文来源无关；已翻译和未翻译的文本都会记录。

文本中的数字统一记录为 `{0}`、`{1}`，同一类别中相同的句子只记录一次，文件不会无限增大。

希望重点覆盖的内容：SkyBlock 菜单及其子菜单、集市、拍卖行、技能、收藏、宠物、配饰袋、各 NPC 商店、地牢与各岛屿的任务提示。

## 隐私说明

- 文件只写在本地，模组不会上传任何内容；是否发送由参与者自行决定。
- 玩家本人的游戏名在写入时替换为 `{玩家}`。
- 不记录玩家聊天、私信，以及公会、组队、合作频道的消息；Tab 列表中的真实玩家条目不记录。
- 系统消息中可能出现其他玩家的名字（如「xxx joined your party」），发送前可用文本编辑器自行检查。

不想参与时，在设置 → 原文收集中关闭「收集游戏原文」即可；`/translate collect reset` 可清空已收集的内容。

## 维护者：汇总与导入

将收到的文件放入同一文件夹，生成汇总表：

```
python tools/merge_collected.py <文件夹> -o data/收集汇总.xlsx
```

汇总表按类别分为多个工作表（`收集-物品描述`、`收集-聊天` 等），只包含术语表尚未覆盖的原文，并按「出现人数」从多到少排序。「当前译名」是收集时游戏中显示的译文，可能来自社区语料或 AI，仅供参考。

在「校对译名」列填写译文后，作为补充表导入：

```
python tools/import_terms.py data/SkyBlock术语表.xlsx data/收集汇总.xlsx
```

导入脚本只读取已填写「校对译名」的行。译文中需保留 `{0}` 等数字占位，占位与原文不一致的行会被跳过。
