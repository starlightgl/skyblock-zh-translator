# SkyBlock 物品命名规则（D 表）

适用于物品名的显示译名。逐条译名、别称和来源见同目录的 `D_out.tsv`。

## 0. 依据与原则

- 中国玩家社区（B站专栏和视频、贴吧、巴哈姆特、中文 Wiki）的实际情况：**大多数高端物品平时直接写英文**，例如“necron鞋子”“5星sa披风”“bonzo头”“Terminator一人一把”“fot价格暴跌”。有中文叫法的主要是少数外号，例如神剑、小黑剑、龙剑、小丑头、盾剑、冰棒、加速剑、紫刀、蓝刀、狗剑、神药、光镐、冰套。
- 因此规则分两层：
  1. **主译名**：中文，可以直接当物品名显示。优先采用社区已经写过的中文名，其次与同行项目 SkyBlockZH 的已定译法对齐，最后才按本规则自拟。
  2. **别称**：放社区外号和英文缩写（AOTE、AOTV、AOTD、Term、Hype、SA、LB、FoT、HPB 等），用于搜索匹配或悬浮提示，**不用作显示名**。
- 原 `D_items_notes.tsv` 备注中的“社区常称”有不少找不到任何出处，例如“海ペ”“土豪金剑/5000万金剑”“金勺子/1亿金勺”“免伤剑/幽灵剑”“合金钻/神圣钻”“神圣套”“末影套（FD）”“奴隶”，以及把 Hurricane Bow 记成 Runaan's Bow 的别称。这些已在 D_out 中删除，删除原因写在“依据”列。
- 原版 Minecraft 已有官方简中名的成分，一律使用官方译名，例如 Wither=凋灵、Packed Ice=浮冰、Glowstone Dust=荧石粉、Slimeball=黏液球、Nether Quartz=下界石英、Baked Potato=烤马铃薯。

## 2. 装备部位

| 英文 | 译法 | 备注 |
|---|---|---|
| Helmet | 头盔 | 社区口语为“X头” |
| Chestplate | 胸甲 | |
| Leggings | 护腿 | 社区口语为“X裤子/X腿” |
| Boots | 靴子 | 社区口语为“X鞋子/X鞋” |
| Cloak | 斗篷 | 社区说“披风”，放入别称 |
| Necklace / Belt / Gloves / Bracelet | 项链 / 腰带 / 手套 / 手镯 | |
| Mask | 面具 | |

- 格式为 **{套装名}{部位}**，中间不加“的”。例如：耐克伦头盔、暗影刺客胸甲、极冰护腿。
- `X Armor <部位>` 中的 Armor 省略，写作 X 加部位，例如 Lapis Armor Helmet 译为“青金石头盔”。只有省略后会与另一套撞名时才保留，例如 Farm Suit 译“农场套装头盔”，Farm Armor 译“农场护甲头盔”。
- `<部位> of X`（Divan 套）同样写作“迪万头盔”。
- 套装总称写作“X套”，例如 SA套、龙套、冰套、悲伤套，只放在别称里。

## 3. 龙套统一格式

**{形容词}巨龙{部位}**，别称写 **{形容词}龙套**。

| 英文 | 主译名前缀 | 社区写法（别称） |
|---|---|---|
| Superior | 卓越巨龙 | 超级龙（B站作“超级神龙”）。保留“卓越”，与原表和 SkyBlockZH 一致。 |
| Strong | 强韧巨龙 | 力量龙 |
| Young | 年轻巨龙 | 幼龙、迅捷龙 |
| Unstable | **失衡巨龙**（原为“不稳定巨龙”） | 贴吧“失衡龙套”，B站“失衡雷龙” |
| Wise | 智慧巨龙 | 睿智龙（贴吧“睿智龙套”） |
| Old | 苍老巨龙 | 远古龙。不用“远古”，因为重铸 Ancient=远古，叠用会出现“远古 远古巨龙头盔”。 |
| Protector | 守护巨龙 | B站作“守护坚龙” |
| Holy | 神圣巨龙 | |

龙碎片同样处理，例如 Superior Dragon Fragment 译“卓越巨龙碎片”。

**Aspect of the X 系列统一译为“X缩影”**：末地缩影、虚空缩影、巨龙缩影、杰瑞缩影。依据是中文 Wiki 页面标题“終界縮影”和贴吧的“末地缩影/巨龙缩影”。原译“X之面”在任何来源里都没有出现。B站另有“化身”的写法，已放入别称。

## 6. 专名音译

- 人名或神名用通行汉译：海伯利安、瓦尔基里、斯库拉、阿斯特赖亚、弥达斯、代达罗斯、欧几里得、高斯、毕达哥拉斯、图灵、牛顿。
- **Midas 统一为“弥达斯”**，原为迈达斯。依据是 B站“弥达斯之剑（黑市剑）”，B 表的 King Midas 也已定为“弥达斯王”。
- 型号照抄，品类词翻译，例如“钛钻头 DR-X455”“个人压缩器 4000”“光轮镐 2000”。
- 物品名中的 `X's Y`：普通物品写作“X的Y”，例如邦佐的面具、耐克伦的剑柄、迪亚曼特的剑柄；套装部位不加“的”。
- **待统一的冲突**：
  - Necron：D 表物品多数用“耐克伦”（10 处），D 表 Boss、染料、皮肤用“内克龙”（3 处），A 表用“尼克隆”。建议全项目统一为“耐克伦”，因为“内克龙”容易让人误以为是龙。
  - Livid：D 表作“利维德”，A 表作“莱维德”。
  - Superior：D 和 SkyBlockZH 作“卓越”，A 表作“至高之龙”。

## 8. 消耗品要点

- Booster Cookie 译“增益曲奇”，与商店的网络加成 Boosters 区分，依据 SkyBlockZH。
- God Potion 主译名为“神之药水”，别称“神药”（B站“蹭神药”）。
- Hot Potato Book 译“土豆书”，别称土豆书、HPB；Fuming Potato Book 译“冒烟土豆书”。**现行 table_names.json 把 Hot Potato Book 也映射成了“冒烟土豆书”，两者撞名，需要修正。**
- Recombobulator 3000 译“重组器 3000”，与 A 表一致。
