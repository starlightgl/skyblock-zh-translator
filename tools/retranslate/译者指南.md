# SkyBlock 中文翻译：译者指南（社区版重翻）

## 目标
把 Hypixel SkyBlock 游戏文本翻译成中国玩家社区的说法。**不参考任何旧翻译**，以社区术语表为准。显示文本里尽量不留英文。

## 术语来源（按优先级）
1. `glossary.tsv`（同目录）：社区术语表，列为 英文/主译名/别称/分类/可信度。凡是表里有的词，**必须用主译名**，包括它出现在句子里、出现在别的名字里时（如 Ferocity 一律「残暴」，Minion 一律「小人」，Defense 一律「防御」）。
2. `D_rules.md`（同目录）：物品命名规则（Enchanted XX→附魔XX，部位、龙套格式、饰品四级链、武器类别词等）。
3. 原版 Minecraft 已有官方简体中文名的物品、方块、生物、附魔、药水效果，用官方译名（如 Wither 凋灵、Packed Ice 浮冰、Nether Wart 下界疣、Sharpness 锋利）。
4. 以上都没有的：按 MC 中文社区习惯意译或音译，简洁自然；人名/专有名可音译，但要像游戏里的名字。

## 统一决定（覆盖其他来源）
Necron 耐克伦，Livid 利维德，Superior 卓越，Renowned 至高，Bits 点券，Gems 宝石币，Coins 硬币，Hot Potato Book 土豆书，Fuming Potato Book 冒烟土豆书，Ferocity 残暴，Defense 防御，Crit Chance 暴击率，Crit Damage 暴击伤害，Magic Find 魔法寻宝，Intelligence 智力，Mana 法力，Health 生命值，Strength 力量，Speed 速度，Minion 小人，Slayer 猎手，Hub 主城，Bazaar 集市，Auction House 拍卖行，Essence 精粹，Reforge 重铸，Recombobulator 重组器，HOTM/Heart of the Mountain 山之心，Powder 粉末，Golden 金（金龙），Dragon（生物、宠物）龙，龙套装按 D_rules（卓越巨龙头盔），Wither 凋灵（药水效果 Wither 为「凋零」），稀有度：COMMON 普通 / UNCOMMON 罕见 / RARE 稀有 / EPIC 史诗 / LEGENDARY 传说 / MYTHIC 神话 / DIVINE 神圣 / SPECIAL 特殊 / VERY SPECIAL 非常特殊 / ULTIMATE 终极 / ADMIN 管理员。修饰词 Legendary 为「传奇」（与稀有度区分）。

## 格式要求（必须遵守）
- 占位符原样保留且数量一致：`{0}` `{1}` …、`{物品}`、`{玩家}`。可以调整顺序。数字后的单位按中文习惯：`{0}s` → `{0} 秒`，`{0}m` 视上下文为「分钟」或「百万」，`{0}k` 保留为 `{0}k`，`{0}x` 倍率写成 `{0} 倍`、数量写成 `{0} 个`。
- 保留所有符号与图标字符（❤ ❈ ✎ ⸕ ☘ ✦ ❁ ⫽ ☠ ⚔ ✯ ☯ ♨ ⏣ ➜ ▶ • ‣ ◆ 以及 \uE0xx 这类私有区字符），放在原来对应的词旁边。
- 罗马数字等级（I、II、XV）保留。指令（/warp、/bz）、按键（Shift、CTRL、左键/右键用中文）、物品编号保留英文。其余玩家可见文字都译成中文。
- 「标签: 值」格式的行保留英文半角冒号加空格：`Mana Cost: {0}` → `法力消耗: {0}`。
- 句子用中文全角标点（，。！？）。类型为「整句」的条目是游戏里跨多行的一整句，翻成一整句（不要分行）。
- 全大写的稀有度行（如 `EPIC BOOTS`、`LEGENDARY DUNGEON SWORD`）译为「史诗靴子」「传说地牢剑」。
- 只翻译，不加解释。拿不准的条目在「备注」列写「待确认」并简述原因。

## 输出
TSV（UTF-8，制表符分隔），表头：`英文\t译文\t别称\t备注`。
- 「英文」列原样复制输入的英文（一字不改，用于对回）。
- 「别称」只在物品/生物/宠物名称上填：社区外号、英文缩写（用 / 分隔），没有就留空；句子不填。
- 输入每一行都要有输出行，顺序一致。

## 已定惯例（前几批译者确定，后续保持一致）
- 名称后缀：(NPC)、(裂隙 NPC)、(怪物)、(海怪)、(首领)=Boss、(小头目)=Miniboss、(市长)、(动物)。带等级的名称写 `[等级 {LVL}] X`。
- Shard 译「碎片」，Fragment 译「残片」（如 邦佐残片、阿拉克涅残片），二者不要混用。
- Sack 收纳袋；Booster 增幅器；Master Star 第X颗大师之星；Abiphone 阿比手机；Minion「X小人」（别称 X仆从）。
- 宝石品级：Rough 粗糙 / Flawed 有瑕 / Fine 精细 / Flawless 无瑕 / Perfect 完美（如 精细琥珀宝石、精细红宝石）。
- 库德拉装备等级：Basic 基础 / Hot 炽热 / Burning 燃烧 / Fiery 烈焰 / Infernal 炼狱。
- 背包：Small 小型 / Medium 中型 / Large 大型 / Greater 超大 / Jumbo 巨型。
- 原版官方名中自带的英文（TNT）和型号（Mk.、FTX 3070 等）可以保留。
- 修饰词（重铸词）只在名字里确实是重铸前缀时才套用修饰词译名；普通形容词按意思翻。
- 句子里的普通词按语境翻：Chance=几率、Light Level=光照等级、Obtained=获得、Blessing=祝福（专有名除外）。Wisdom 作属性为「智慧」（如 战斗智慧）。Hunter=猎人（Slayer=猎手）。
- 其他已定：Spooky Festival 惊魂节、Fishing Festival 钓鱼节、Season of Jerry 杰瑞季、SkyMart 天空超市、Tiered Bonus 阶梯加成、Travel Scroll 传送卷轴、Mob Types 生物种族、MM/Master Mode 大师模式、EHP 有效生命值、Soul Pieces 灵魂碎块、Superior Dragon 卓越巨龙、SkyBlock（年份、等级等）译「空岛」。
- 单位：`{0}M` 数量为「{0} 百万」，时长 `{0}m` 为「{0} 分钟」，`{0}h` 为「{0} 小时」，`{0}d` 为「{0} 天」。
- 模组名（NEU、Skyblocker 等）、玩家名保留英文。
- **私有区图标字符（\uE0xx，游戏里显示为属性图标）必须保留**，放在对应中文属性名前面（如 `+{0} Strength` → `+{0} 力量`）。写 Python 时用 \ueXXX 转义。
- 生物种族列表用「、」分隔；Spooky 惊魂、Elusive 隐匿、Subterranean 地底。期号「Edition #{0}」写「第 {0} 期」。等级前缀统一「[等级 {LVL}] X」。
- Revenant 一律「亡魂」（如 亡魂恐魔、亡魂靴子），Undead 为「亡灵」。Timid 胆小，Magmatic 熔岩，Awkward Potion 粗制的药水（原版官方名）。
- 集市：Buy Order 收购订单、Sell Offer 出售挂单、Instant Buy 立即购买、Instant Sell 即时出售；拍卖行 BIN 一口价。巧克力工厂：Rabbit Barn 兔子谷仓、Time Tower 时间塔、Chocobit 巧比特、Coach Jackrabbit 杰克兔教练、Director 总监、Executive 高管、Board Member 董事。
- 狩猎属性 Charm（Charm Chance）为「魅力」，附魔 Charm 为「鱼魅」。Umber 一律「赭石」，Helianthus「日轮葵」，Fermento「发酵素」。Fragment 译「残片」，唯龙碎片（X Dragon Fragment）用「X巨龙碎片」。
- NPC 聊天：`[NPC] 中文名: …`（半角冒号）。{0}B 为「{0} 十亿」。
